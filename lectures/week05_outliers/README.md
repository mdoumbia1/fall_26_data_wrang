## Topics

- Kinds of outliers: error, contamination, genuine extreme
- Detection: z-score, IQR rule, modified z-score
- Masking, breakdown point, and the z-score ceiling $(n-1)/\sqrt{n}$
- Right-skewed data and log scales
- Multivariate outliers
- The four kinds of inconsistency: representation, units, format, contradiction
- Handling flagged values, and measuring data quality

> **The rule to remember:** removing a point needs a *cause*, not just a distance.
